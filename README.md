# 🤖 AI Agent

Repositorio dedicado al desarrollo de **agentes de Inteligencia Artificial
basados en Large Language Models (LLMs)** utilizando LangGraph y LangChain.

El objetivo es mostrar diferentes componentes y patrones utilizados en
la construcción de agentes capaces de interpretar solicitudes, planificar
acciones, seleccionar herramientas y ejecutar flujos de trabajo
multi-step.
